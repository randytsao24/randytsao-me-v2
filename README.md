# 🐸 Randy Tsao's Personal Website 🐸

This repository contains the source code for my website, which is built with Gatsby and hosted on Netlify.

### Dev Setup

1. Clone the repository:

```bash
git clone https://github.com/randytsao24/randytsao-me-v2.git
cd randytsao-me-v2
```

2. (OPTIONAL) Install the correct Node.js version:

```bash
nvm install
nvm use
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run develop
```

The site will be available at `http://localhost:8000`. The GraphiQL interface can be accessed at `http://localhost:8000/___graphql`.
